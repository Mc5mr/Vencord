# Mc5mr Equicord downloads

This branch distributes compiled Windows x64 installer and app updates. Installation and update checks do not require an account, password, GitHub CLI or token.

Download the installer from this repository's Equicord releases. `latest.json` is updated only after all release files are published and verified. The installer's included app package remains usable offline.

This distribution branch is separate from the repository's default branch. It contains the publication helper and compiled release metadata; custom development source is maintained separately.
